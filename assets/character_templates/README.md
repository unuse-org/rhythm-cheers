# キャラクター生成素材

`normal.png`から`failure.png`は、顔を合成する身体テンプレートです。5枚とも628×1116の透過RGBAへ揃えています。

`default_hair.png`、`success_overlay.png`、`failure_overlay.png`は、実行時に白背景を除去しないよう事前に透過処理済みです。

`haarcascade_frontalface_alt.xml`はOpenCV 4.12.0の公式配布データを使用しています。OpenCVのライセンスは`native/kanpai_image/third_party_licenses/opencv.txt`を参照してください。

身体・髪・表情素材は、このプロジェクトで制作した自作素材です。
