# Godot 4 (macOS / Apple Silicon) ビルド・エクスポート手順まとめ

## 1. プロジェクト設定の修正 (テクスチャ圧縮)
Apple Silicon (M1/M2/M3/arm64) 向けエクスポートで必要なテクスチャフォーマットを有効化します。

- **プロジェクト > プロジェクト設定 > レンダリング > テクスチャ**
- `Rendering / Textures / VRAM Compression / Import ETC2 ASTC` を **有効 (オン)** にしてプロジェクトを保存・再起動。

---

## 2. エクスポートプリセットの設定 (macOS). 
(別ブランチに移動するたび、ローカル環境で以下全てを設定しなおしてください)
**プロジェクト > エクスポート** より macOS プリセットを追加し、以下の項目を設定します。


### 基本設定
- **Bundle Identifier:** 識別子を入力（例: `com.kanpai.game`）

### 高度なオプション (画面右上のトグルをオン)
- **Entitlements:**
  - `Disable Library Validation`: **有効 (オン)**
    - ※アドホック署名環境で GDExtension (`.dylib`) を読み込むために必須。
  - `Camera`: **有効 (オン)**
- **Privacy:**
  - `Camera Usage Description`: カメラ使用理由を入力（例: `ゲームプレイの画像認識に使用します`）

---
